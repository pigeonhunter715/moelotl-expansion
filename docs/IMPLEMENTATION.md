### 运行测试中修复的问题

1. 临战状态创建时，原版OnStageIndexChanged假定CurStage非空；计时器尚未初始化时改为安全跳过空阶段回调，保留到期无加成。
2. 预留药种原先不阻止手动装入第七类，现将预留与实物合并检查。
3. 分批补货原先越过半仓阈值就停，现保存进行中的补货需求，持续至目标。
4. 动态质量原版不可变缓存及StatRequest重载遗漏，现仅对玉佩绕过缓存、在统一最终查询加一次内装属性；财富遍历排除重复计数。
5. 纳煞到期普通GameComponent运行顺序太晚，现将预约结算移至角色tick之前。
