测试分支：`dev`。隔离游戏：RimWorld 1.6.4871 rev591；本体、螈僵扩展、Harmony、HAR、CQF、本扩展。未使用正式存档或正式游戏配置。

## 360 天生产模型

可复跑命令：`python tools/production-sim.py`。脚本从本仓库丹药配方 XML 读取批次原料；运行时本体运气丹与丹剂参数已由 RimSearcher Def 快照核实。排程按离散批次事件推进，不把小数枚药当成可交付库存。

假设为五只活体萌螈和一只己方螈僵，4座通天仪各连接4根精粹之柱，单炉按理论产能的80%有效开工，燃料和丹剂可以及时供应。A炉专门炼运气丹；B炉轮换回元丹与聚煞丹；C、D炉轮换临战、镇煞、涤煞、纳煞和安魂。初始成品库存采用设计表目标，另为有限的运气丹成长需求准备5枚。需求采用设计中的最高可用频率压力值，而非普通游玩的预测均值。

期内批次已开工6168进度，设计平均需求约6168.6进度；80%可用产能预算约6400进度。开工量约占四炉理论物理产能77.1%，占80%规划预算96.4%。批次排程能覆盖所列压力需求，但余量不大，需求之外的额外狂暴、停工或燃料断供需从库存与余量另行承担。

按当前配方 XML 统计的原料净用量：精神叶45.233/天、玉琼粉58.867/天、草药7.733/天、桃木17.378/天、阴沉木5.667/天、鸡血2/天、虫血0.667/天、铀4.872/天、黄金按原配方理论量1.944/天、不化骨0.2/天。另需约93889单位化合燃料/360天，即260.80/天。运气丹黄金的实际整数扣料仍不在本测试覆盖内。

模型按药物目标库存触发整批生产，批次完成后再交付；结束时单列在制批次。它假设原料、丹剂和燃料已准备好，不模拟种植周期、矿物采集、搬运工作者、仓库预留、设备周边布局、炉边补燃料、随机事故或玩家微操，因此结果是排程和库存曲线验证，不是殖民地实战保证。80%有效率也是模型输入而非游戏测量。

## 游戏内炉速

功能测试在游戏地图生成通天仪及四根相邻精粹之柱，放入1份回元丹剂并加入31单位化合燃料。原炉启动后，经其真实炼丹进度方法按60 ticks 步长推进。前360步累计为 `1.999994 / 2`，没有触发完成；第361步后生产12枚回元丹，燃料剩 `0.9166`，即该批消耗约30.0834。这是通过调用本体进度方法累计的21660个进度ticks，地图时钟实际未推进。

这说明原炉的逐段浮点累加会略低于理论批次阈值，精确加入理论30单位时无法完成。模型保守地将每批进度对应燃料按整单位向上留量；实际批次最低燃料可能因药种和进度不同而有不足1单位的余量。这里测试的是炉体原生炼丹进度/扣燃料方法，隔离炉体日常照明和CompRefuelable维护；未实测长期殖民地的燃料搬运。
