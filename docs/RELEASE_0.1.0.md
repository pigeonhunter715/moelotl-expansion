# 萌螈丹药扩展 v0.1.0 发行检查

适用 RimWorld 1.6。安装文件为 `moelotl-expansion-v0.1.0-rimworld1.6.zip`，大小 1,620,253 字节，SHA256 为 `aec315f97463fb677ef2b6e5a0ef15f51690219bc8c0629609178ca09dac504f`。解压后，`MoeLotlExpansion` 文件夹可直接放进 `Mods`。[安装说明](INSTALL.md)

| 检查 | 验证结果 |
|---|---|
| 构建与规则 | 使用 RimWorld 1.6 依赖程序集编译，52 项规则断言通过。 |
| 数据 | 11 种丹药、7 种丹剂、配方与效果、XML 及中英界面键通过静态检查。 |
| 发行文件 | 29 个文件解压后逐一核对 SHA256。唯一的 DLL 是本扩展程序集；隔离游戏从已解压发行目录加载。 |
| 游戏功能 | RimWorld 1.6.4871 rev591，全部五个DLC及当前依赖：50 项功能断言通过，游戏正常退出。 |
| 存档回归 | 同版本及依赖：72 项保存重载、药效、安魂、续药、炉接口和补货断言通过，游戏正常退出。 |
| 生产排程 | 五只萌螈、一只螈僵、四座各配四柱的通天仪、80% 开工率及持续供料下，360 天压力模型各药缺货次数均为零。 |

日志保留了既有英语翻译提示；测试场景生成本体缠风剑时也记录了未指定材料的提示。两轮测试的成功标记分别为 `FUNCTIONAL_COMPLETE checks=50` 与 `COMPLETE checks=72`，没有本扩展未处理异常或XML加载错误。此前的无DLC 72 项回归见[兼容矩阵](PRODUCTION_COMPAT_REPORT.md)。

验证局限：不涵盖其它依赖版本或模组组合、RimWorld 1.7、完整殖民地长期搬运与市场供料、额外武器与技能兼容。生产排程是给定供料及开工率的模型，不构成实际产量保证。
