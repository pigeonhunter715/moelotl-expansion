# 太阴丹

太阴丹是后期的至阴至煞丹药。符合资格的飞僵服下后会蜕变为太阴仙体，获得更强的肉身与神志。资格不足者服下即死。本文整理设计与定稿文案。

## 配方与炼制

| 每炉材料 | 数量 | 本体物品标识 |
| --- | ---: | --- |
| 飞僵尾巴 | 3 条 | `AxoZombieTailE` |
| 毛僵尾巴 | 30 条 | `AxoZombieTailD` |
| 阴沉木 | 300 | `RM_OvercastWood` |
| 虫血 | 3,000 | `RM_InsectBlood` |
| 玉琼粉 | 3,000 | `Axolotl_JadeEssencePowder` |

- **制作解锁**由「传世至宝」把关，同时需要完成「炼尸」和「炼丹工坊」。手工至少 10 级，在捣药台配成一份丹胚。
- **炉期**为通天仪累计有效炼制一个游戏年，即 60 天（3,600,000 ticks），累计消耗约 5,000 化合燃料。停炉保留进度，复炉继续累计。简易炼丹也按一年结算。
- **产量**为每炉 1 枚。玉琼粉在炉炼中吸纳阴气与煞气，成为承载药力的丹胎。
- **外观**为纯黑色丹丸，表面无纹样。

## 服用资格

蜕变须同时满足下列条件。

- 己方、已苏醒的飞僵，且当前未处于螈僵狂暴。已狂暴的个体先用安魂丹恢复控制。
- 死脉达到**八脉**。本体 `RM_DeathMeridians` 的八脉是最高阶段，内部严重度为 5。
- 拥有原版「善良」特性（`Kind`）。
- **成为螈僵后累计击杀至少 1,000 名人类**。按原版「击杀（人类）」的归因和统计口径计数，螈僵升阶后继续累计。

太阴丹只通过手动自服或人工喂服使用，每个角色仅有一次成功蜕变的机会。服药界面显示资格与结算结果。吞服动作完成时消耗 1 枚，并按当时的角色状态判定。符合全部条件者完成蜕变，资格不足者当场死亡。飞僵本体的不死和再生能力无法免除此结算。设定上，死脉或心神承受不住暴涨的阴煞，神志与身躯随之崩毁。

## 蜕变效果「太阴仙体」

蜕变成功后永久获得「太阴仙体」。飞僵在感受众生之苦后仍能守住神志，煞气超容时免于因此狂暴。煞气条继续显示实际数值。煞气积累、容量及本体战斗收益沿用原规则。

乘数在飞僵本体和煞气已有的属性修正基础上叠乘。意识采用百分点加成。

| 属性 | 太阴仙体加成 | 结算范围 |
| --- | ---: | --- |
| 承伤 | ×0.50 | 对本体判定后仍生效的伤害再减免 50% |
| 自愈速度 | ×3.00 | 提高本体「自愈因子」每次的修复量，包含已有的伤口、器官和肢体再生，沿用各部位的修复倍率 |
| 倒地后的再生停顿 | 30 秒 → 10 秒 | 缩短本体因倒地施加的停愈，独立施加的停愈照原有效果结算 |
| 近战伤害 | ×1.50 | 强化爪击、撕咬及读取近战伤害系数的攻击 |
| 近战冷却 | ×0.50 | 已有近战攻击间隔减半 |
| 移动速度 | ×1.35 | 体现在日常移动和战斗走位 |
| 意识 | +100 个百分点 | 增加意识能力值，伤势和其他能力修正继续参与结算 |
| 饥饿速率 | ×0.50 | 饥饿消耗减半，体现蜕变后对进食需求的减轻 |

蜕变成功时同时获得两项永久特性。

- **沉鱼落雁**采用原版 `Beauty` 的 2 级，容貌 +2。已有原版同系容貌特性时替换为该档，已有该档时沿用原记录。
- **博闻强识**采用《异常》的 `PerfectMemory`，使技能经验免于自然衰退。已有该特性时沿用原记录。未启用《异常》时，授予同名、同效果的扩展特性。

「太阴仙体」随个体存档，在远行和返回地图后保留。纳煞、涤煞与夜叉珍珠按现有规则联动。归真丹继续解除涤煞与夜叉珍珠。安魂丹继续承担已经发作的狂暴救急。

旧存档的专用击杀记录从启用本版本起算。该记录只计角色在螈僵期间获得的合资格击杀。变回其他形态、失去善良特性或苏醒状态时，太阴仙体的属性和防狂暴效果暂停，恢复资格后继续生效。成功蜕变时获得的两项特性作为永久特性保存。

## 游戏内物品描述（定稿）

丹成之日，炉中霜厚三寸。握在掌心，隐约能听见哭声。

飞僵吞下太阴丹，积煞立刻沿死脉暴涨，仿佛每一寸经脉都从里向外裂开，即便是它也来不及复原。它感受身体的撕裂，好似下一刻便要死去。更加痛苦的是——它曾夺去千条性命，如今阴煞将那些人死前的恐惧一一还给它。它听见濒死的人喊着母亲，看见恋人恐惧得攥紧身边人的手，闻见刺鼻的血腥弥漫口腔。它突然意识到，那些曾被它视作猎物的众生，那些被它戏谑虐杀的玩物也会怕痛，也舍不得死。

它释然了，原来自己是这样的怪物吗，它不再挣扎，任由阴煞撕裂经脉，搅烂腑脏，碾碎骨骼——是时候死去了，其实它早该死去了，不是吗？

……

“我还活着？”待最后一声哭泣止息，它看向自己千疮百孔的身躯——它，活下来了。

自此凡躯尽蜕，煞气再盛，亦不能夺走它的神志。那股曾令它屈服的嗜血之性，终于在这一炉至阴至煞之中褪尽。
