# 萌螈丹药扩展 v0.2.1 发行检查

适用 RimWorld 1.6。安装 ZIP 为 `moelotl-expansion-v0.2.1-rimworld1.6.zip`，大小 1,745,531 字节。解压后将 `MoeLotlExpansion` 文件夹放入游戏的 `Mods` 目录。[安装说明](INSTALL.md)

ZIP 的 SHA-256 为 `76b4ca0371672f447d06ce11a341e074b203cd737383cb368cd31351f53ddf83`。

| 检查 | 验证结果 |
| --- | --- |
| 构建与规则 | 使用 RimWorld 1.6 依赖编译，50 项规则检查通过。 |
| 数据 | 12 种丹药、8 种丹剂或丹胚、11 条五倍配方、成药研究展示及中英文键通过静态检验。另有 51 项外部 Def 引用对照运行时快照通过。 |
| 发行文件 | 正式 ZIP 中的 38 个文件解压后逐一核对 SHA-256，包括太阴丹在内的全部 4 份中英文界面文本均在包内。包内 DLL 为本扩展程序集。 |
| 存档回归 | 从已解压的发行包启动 RimWorld 1.6.4871 rev591，150 项存档回归通过。覆盖两类丹炉、太阴蜕变与存档重载、玉佩负重和自动用药。 |
| 游戏功能 | 同一发行包通过 56 项功能检查。覆盖实际自服和喂服、补货与商队、原生近战与连弩命中、太阴丹炉期。 |
| 生产排程 | 五只活体萌螈、一只螈僵、四座各配四柱的通天仪，以 80% 开工率且持续供料模拟 360 天。每三天一场五人战斗时无缺货。 |

功能测试夹具会复用螈僵自行起跳时已有的飞行容器，以覆盖空中安魂而避免重复装载。

实机使用隔离存档与仓库列出的前置模组，启用了当次测试配置中的五个 DLC。生产排程使用设定的开工率和原料供给。实际殖民地供料以及其他依赖版本和模组组合未纳入本轮发行验证。本版补齐了 v0.2.0 安装包遗漏的太阴丹界面文本。此前的记录见[发行检查 v0.2.0](RELEASE_0.2.0.md)。
