# 丹药第二版：乳白丹体与彩色纹样

2026-11-19。本轮按用户确认的纹样方案重绘十一种丹药，保留药渡玉佩第二版。形状来源与传统含义的边界见 [纹样方案](PILL_MOTIFS.md)。

## 制作规则

统一圆润乳白丹体、暖灰阴影、右上小高光、深色外轮廓和原创折纸底托。纹样以宽笔画和留白表达，颜色只用于表面药纹；底稿实测纹样占可见丹体面积约16%—24%，镇煞丹的直剑构图约12%，以保留两侧留白。回气丹为横向舒展云纹，聚煞丹为三股向心勾云。百工丹的盘长简化为交织回环带，涤煞丹为闭合回纹环，避免二者都变成方框。

采用 `tools/pill_art.py` 绘制独立原创底稿，再由本机 ComfyUI 0.46.0／SDXL Base 1.0 进行低强度图生图。没有输入馆藏照片或原模组贴图，也没有沿用第三方透明遮罩。球面、纹样、折纸和透明遮罩均来自本仓库底稿，AI主要细化明暗与表面。模型权重不随模组分发，许可为CreativeML Open RAIL++-M。

提示词用乳白圆粒、火焰尖瓣、水平波线、交织带、圆云头、直剑、宽腹瓶、闭合回折环等可见形状描述，不包含萌螈、螈气、煞气或丹药中文名。完整正负提示词记录在各物品的API工作流。

## 参数与复现

1024×1024输入，30 steps，CFG 5.5，DPM++ 2M / Karras，denoise 0.22。种子为基础值2026112100加物品索引0—10。先生成暖脉、清暑、百工、涤煞作为试样，已检查乳白底色、交织间隙和闭环完整性，再生成其余七药。

```powershell
python tools/generate-item-art.py --comfy '<本机ComfyUI目录>' --limit 11 --seed 2026112100 --denoise 0.22 --output artifacts/art-style/pills-v2/generated
```

`--only`可重复指定单个Def名，仍保留固定索引与种子。每个物品单独保存manifest，分批生成不会覆盖别药记录。选取11药时使用 `python tools/review-item-art.py --source artifacts/art-style/pills-v2/generated --pills` 重建预览，并在视觉检查后添加 `--publish`。未选中的玉佩直接使用现行发行PNG。`record-pill-art.py --source artifacts/art-style/pills-v2/generated` 校对源图哈希、最终PNG、参数和节点坐标并保存工作流。

仓库工作流目录：`docs/art/pills-v2/`；对应底稿需先通过生成器写入本机ComfyUI的input目录，单独导入JSON并不会自动下载输入图。ComfyUI Workflows中的名字为 `2026-11-19_moelotl_v2_MX_<名称>Pill.json`，可在本机 `http://127.0.0.1:8188` 打开。API与GUI使用同一组参数；不同软件／硬件不保证逐像素复现。
