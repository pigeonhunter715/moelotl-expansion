# 物品贴图风格与制作记录

## 当前方向：乳白丹体与中国纹样

2026-11-19用户追加要求：十一种丹药统一乳白色丹体，按用途配置彩色中国纹样。选型、馆藏依据、颜色和不使用专有名词的形状提示见 [丹药纹样方案](PILL_MOTIFS.md)。该方案覆盖下文首版的彩色丹体及识别纹样；下文保留为首版制作与验收记录，不是第二版已经完成的声明。本轮仅完成资料整理，当前PNG、生成脚本、预览和生成记录仍对应首版。药渡玉佩方向保持现有记录。

## 观察依据

2026-11-19 检查本机已下载的 MoeLotl Race（Workshop 3292351432）和 MoeLotl: Rigor Mortis（3454053400）实际 PNG。重点样本为本体运气丹、回脉丹、玉琼粉，以及附属模组夜叉珍珠、铜铃、八卦镜、桃木剑、胭脂盒。运行时 Def 快照中两个本体丹药的 graphicData 指向对应 PNG，使用 Graphic_Single、Cutout 和白色色调；快照不是当前所有模组加载组合的实时证明。

参考拼图仅保存在忽略的 artifacts/art-style/reference-sheet.png，未将第三方贴图复制到发行目录或仓库。面部动画、近战动画兼容补丁没有被当成物品美术标准；这里的结论针对上述物品样本，不代表全部角色、建筑和特效。

| 特征 | 实际观察 | 新图的处理 |
| --- | --- | --- |
| 轮廓 | 深色粗描边，形体完整、略有手绘感 | 深炭色外轮廓，内部线条更细 |
| 视角 | 正面略俯视；圆粒配菱形药纸，武器多为斜向陈列 | 丹药置于新画的折纸上，玉佩正面陈列 |
| 明暗 | 大块底色、局部渐变和少量硬边阴影并存 | 限制暗部层次，避免噪声和写实表面 |
| 光泽 | 圆粒上有大白色亮斑和小亮点；原图高光方向并非完全一致 | 统一右上高光，纸上接触阴影向下 |
| 材质 | 药丸接近蜡质/釉面；玉石有少量曲线，木器有色块和线纹 | 用曲线、叶片、弧纹等少量可辨标记表达差异 |
| 配色 | 本体药物浅奶白、米黄；附属物品青绿、土棕、暗红较多 | 当前目标：乳白丹体＋按用途配色的纹样，保持暖纸色；首版彩色丹体待替换 |
| 文件 | 检查的两种丹药、玉琼粉和珍珠均为 512×512 RGBA | 新成品同为 512×512 RGBA；检查 128/64/32 像素可读性 |

这是一种带粗线的二维物品插画，不采用像素马赛克、写实珠宝摄影或复杂徽章构图。

## 制作方法

先通过程序绘制新的轮廓、色块、纹样与透明遮罩，再以 SDXL Base 1.0 图生图细化内部色面，最后使用原始底稿的独立遮罩恢复轮廓并清理色键污染。**这是原创底稿约束的 AI 辅助贴图，不是纯文字直出，也不是原模组图标换色。** 发布图像不使用第三方贴图像素或遮罩。

此前直接文字生成和使用第三方丹药图的图生图测试均未采用：前者形状失控，后者过度保留原图。拒绝的测试仅留在本机 ComfyUI 输出目录，不进入模组纹理目录。

参数：1024×1024 输入、30 steps、CFG 5.5、DPM++ 2M / Karras、denoise 0.28、逐张生成；ComfyUI 0.46.0，官方 SDXL Base 1.0。模型受 CreativeML Open RAIL++-M 许可约束，模型权重不随仓库分发。

复现入口：`python tools/generate-item-art.py --comfy <ComfyUI安装目录>`，需 Pillow、NumPy 和本机 ComfyUI 服务。`--start` 和 `--limit` 可指定子集。脚本保存原创透明底稿、实际 API JSON、原始生成 PNG、种子和生成记录到 artifacts/art-style/generated；GUI 工作流保存到 ComfyUI 用户 workflows 目录。更换软件或硬件后不保证逐像素复现。
